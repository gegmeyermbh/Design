# QHD-Wallpaper – Feuerversion

- [Links, Hochformat, 1440 × 2560](Feuerlinie-Links-1440x2560.png)
- [Rechts, Querformat, 2560 × 1440](Feuerlinie-Rechts-2560x1440.png)

Die Oberkante des linken Monitors liegt 95 mm über der rechten. Die beiden Displays melden eine Bildfläche von 697 × 392 mm. Daraus ergibt sich annähernd derselbe Pixelabstand und ein Grundversatz von 349 Pixeln.

Beide Bilder stammen aus einem gemeinsamen, auf 4000 × 2560 Pixel exportierten Motiv. Rechts wird der Ausschnitt (1440, 349, 2560, 1440) verwendet. Links ist es der Ausschnitt (0, 0, 1440, 2560), anschließend um 35 Pixel nach unten verschoben. Diese Feinkorrektur entstand beim Sichtabgleich.

Die Einzelbilder jeweils dem passenden Monitor zuweisen. Die Ausschnitte sind für die beschriebene Anordnung bestimmt. Das generierte Ausgangsmotiv hat 1568 × 1003 Pixel; für die exakten Ausgabemaße wurde es hochwertig skaliert.
